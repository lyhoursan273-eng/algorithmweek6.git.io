04 · Trace the Pointers, Not Just the Values

Watch HEAD, PREVIOUS, and CURRENT as Search Advances

Target = 30. The data values do not move; only the pointer variables change what they reference.

Initial state: previous = NULL; current = head.
previous = NULL; current = head; while (current && current->value != target) { previous = current; current = current->next; }
Mental model: HEAD stays anchored while CURRENT walks and PREVIOUS follows one node behind.

04 · Free the Whole List

Save the Link Before You Free the Node

current = head. First save next = current->next.
Common bug: once current is freed, reading current->next is undefined behavior.
